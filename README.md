# Peaksway Adventures Banasura

Website for **Peaksway Adventures Banasura** – guided treks and hikes on Banasura Hill, Wayanad, Kerala.

A plain static site (HTML + CSS + JS, no build step).

```
index.html          page content
css/style.css       styles (brand colours at the top in :root)
js/main.js          menu, scroll animations, gallery lightbox, WhatsApp enquiry form
assets/images/      logo, photos, posters, brochure, favicons
```

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.

## Publish (free)

GitHub Pages: repo **Settings → Pages → Deploy from branch**, pick the branch and `/ (root)`.
Netlify / Vercel / Cloudflare Pages also work – just point them at this folder.
